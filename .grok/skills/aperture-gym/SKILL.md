# Aperture gym

Read `GROK.md` first.

This repo is the gym. Grok Build CLI is the coding agent working on it.

Continue the **Aperture CLI** (`bin/aperture.mjs`, `/harness/$taskId`). Keep worlds, tools, rewards, and traces exact.

```bash
npm run aperture -- play civic-library --reference
```

Do not build a GUI. Do not start over. Do not upload data.
